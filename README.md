# E2S · Easy to Shot

E2S 是一款 Windows 桌面截图工具，提供截图标注、贴图、文字识别与翻译、二维码扫描、滚动截图和选区录像。应用使用 PySide6 与 PySide6-Fluent-Widgets 构建，主菜单和系统托盘用于管理快捷键、历史与配置。

## 环境要求

- Windows 11 x64，以及可用的系统托盘。
- Python 3.13（64 位）和 Git。建议安装时启用 Python Launcher（`py`）和 pip。
- 首次安装依赖、下载额外 OCR 模型及使用在线翻译时需要网络。
- 录像功能使用 `imageio-ffmpeg` 提供的编码器；录音需要系统中有可用的麦克风或播放设备。

## 从零构建与启动

在 PowerShell 中执行以下命令。将仓库地址替换为你的仓库地址（如有需要），并在克隆后进入项目目录：

```powershell
git clone https://github.com/Obagaii/easy-to-shot.git
cd easy-to-shot
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install .
```

依赖和项目只安装在当前项目的 `.venv` 中，不需要安装到全局 Python 环境。若需要运行测试，在项目目录中额外安装测试依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install ".[test]"
```

安装完成后，双击项目目录中的 `start.vbs` 启动，日常使用不会显示命令行窗口。也可以从命令行运行 `start.bat`；直接双击 BAT 时 Windows 可能短暂显示命令行窗口。两个脚本均使用项目内的虚拟环境和当前源码。

开发时需要查看控制台输出，可以在项目根目录执行：

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) 'src')
.\.venv\Scripts\python.exe -m e2s
```

应用启动后可从主菜单、托盘或全局快捷键开始截图。关闭主菜单后程序继续驻留托盘；从托盘菜单选择“退出”可结束程序。项目当前提供源码运行方式，没有在仓库中提供独立的 EXE 打包脚本。

## 初次配置

### 全局热键与快速截图

在主菜单“全局热键”中配置启动截图及截图工具栏快捷键。默认截图热键为 `Ctrl+Shift+F8`；修改全局热键时，若组合被系统或其他程序占用，请选择其他组合。

在“快速截图”中可配置激活键加鼠标拖动。默认组合如下：

| 功能 | 默认操作 |
| --- | --- |
| 截图复制到剪贴板 | Win + 鼠标左键拖动 |
| 文本识别 | Win + 鼠标右键拖动 |
| 文本翻译 | Win + 鼠标中键拖动 |
| 快速贴图 | Ctrl + 鼠标左键拖动 |
| 录像、扫描二维码 | 默认未设置，可自行配置 |

在配置弹窗中选择 Win、Alt、Ctrl 的一种或组合，再选择左键、右键、中键或侧键拖动。清空激活按键可取消该操作的绑定；重复组合需要先解决冲突。

### OCR 模型与翻译来源

在“OCR 和翻译”中选择本地文字识别模型、默认目标语言和默认翻译来源。识别使用 RapidOCR 和 ONNX Runtime，图片在本机处理：

| 档位 | 模型 | 说明 |
| --- | --- | --- |
| 小 | PP-OCRv6 Tiny | 体积较小，支持的语言较少 |
| 中 | PP-OCRv6 Small | 默认模型 |
| 大 | PP-OCRv6 Medium | 更大的模型，资源需求较高 |

Small 模型通常随 RapidOCR 依赖提供。选择尚未下载的模型时，确认后会后台下载并校验模型文件；下载失败或取消时保留原有选择。模型文件保存在应用的本地数据目录中。下载模型需要访问 RapidOCR 的 ModelScope 模型源。

翻译来源可选择“免费翻译”或“DeepSeek”，也可在截图识别工具栏临时切换。翻译会将识别出的文字发送给所选在线服务。使用 DeepSeek 前，在“AI 模型”中填写并保存自己的 API Key；Key 保存在 Windows 凭据管理器中。DeepSeek 服务需要可用的账户与网络。

## 主要功能

- **截图与标注**：框选屏幕区域，使用矩形、椭圆、箭头、画笔、文字、水印、高亮和橡皮擦等工具，可撤销、重做、复制或保存截图。截图前可使用智能选区预览窗口或控件，也可直接拖动框选。
- **贴图**：将截图固定在屏幕上，可拖动、缩放、复制和保存。点击贴图后，右上角显示编辑和关闭按钮；编辑完成后可应用到贴图。
- **文字识别与翻译**：识别后的文字可以选择、复制或编辑，也可在原区域显示识别文字和译文；翻译支持流式显示。
- **二维码扫描**：本地识别选区中的二维码或条码，结果可以复制，也可打开识别出的网页链接。
- **滚动截图**：支持纵向或横向拼接、自动滚动、预览和裁剪，并可复制、保存或贴图。
- **选区录像**：支持 MP4、GIF 和 WebP；MP4 可选择录制麦克风及系统声音。录像过程中可暂停、继续和标注。
- **截图历史**：查看复制、保存或贴图的截图，按类型和时间筛选，分页、多选、删除及清空；支持预览截图区域和完整屏幕图，并重新打开可编辑的历史记录。

设置、历史记录和下载的模型存储在当前用户的本地应用数据目录下。截图历史会保存完整屏幕图和编辑参数，以便重新编辑；删除历史记录不会删除用户另存到其他位置的文件。

## 常用截图工具栏快捷键

可在主菜单“全局热键”中修改截图工具栏快捷键，也可将多个按键绑定到同一功能。悬停在工具按钮上可查看当前快捷键。

| 功能 | 默认快捷键 |
| --- | --- |
| 移动、选择 | M 或 Ctrl+E、V |
| 矩形、椭圆 | 1、Shift+1 |
| 箭头、画笔、文字 | 2、3 或 P、5 或 T |
| 水印、高亮、橡皮擦 | 9、4 或 H、8 或 E |
| 撤销、重做 | Ctrl+Z、Ctrl+Y |
| 识别文字、扫描二维码、贴图、滚动截图 | Ctrl+O、Ctrl+Q、Ctrl+F、L |
| 录像 | Ctrl+R |
| 保存、取消、复制 | Ctrl+S、Esc、Ctrl+C 或 Enter |

## 运行测试

安装测试依赖后，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest
```

涉及桌面交互的测试需要可用的 Windows 图形会话。若只验证单个功能，可以在命令后指定对应的测试文件。
