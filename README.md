# Easy to Shot

Windows 桌面截图工具。通过工作台、托盘或全局热键开始截图，框选后可以标注、识别内容、输出图片、滚动截图、录制选区或贴图。

## 本地运行

使用 Windows 11 x64 和 Python 3.13。在 PowerShell 中执行：

~~~powershell
python -m pip install ".[test]"
python -m e2s
~~~

- 默认全局截图热键为 Ctrl+Shift+F8。拖动框选，松开后显示工具栏。在移动模式可拖动整个选区，拖动四角或四边中点可缩放。移动或缩放时，工具栏暂时隐藏。
- 在选择模式可单击或框选已绘制的元素，拖动可移动元素，拖动手柄可缩放，按 Delete 可删除。箭头的端点可单独调整。标注使用冻结画面的像素坐标，调整截图选区后，标注随选区裁剪。
- 文字可单击输入、双击重新编辑。Enter 换行，Ctrl+Enter 完成，Esc 取消文字编辑。
- 固定到屏幕后，可拖动贴图移动，拖动边框上的八向手柄或滚动鼠标滚轮缩放。通过右键菜单或 Ctrl+C、Ctrl+S、Esc 复制、保存或关闭贴图。
- 关闭工作台后程序仍驻留托盘。从托盘菜单选择“退出”结束进程。

## 截图工具栏快捷键

悬停可查看名称和快捷键。矩形和椭圆共用形状入口。工具设置条随当前工具切换，可在其中调整描边、填充、箭头形态、字体、对齐、水印模板、高亮模式或橡皮擦模式。拖动左侧握柄可移动工具栏。

| 工具 | 快捷键 |
| --- | --- |
| 移动、选择 | M 或 Ctrl+E、V |
| 矩形／上次使用的形状、椭圆 | 1、Shift+1 |
| 箭头、画笔、文字 | 2、3 或 P、5 或 T |
| 水印、高亮、橡皮擦 | 9、4 或 H、8 或 E |
| 撤销、重做 | Ctrl+Z、Ctrl+Y |
| 识别文字、扫描二维码、固定到屏幕、滚动截图 | Ctrl+O、Ctrl+Q、Ctrl+F、L |
| 保存为文件、取消、复制到剪贴板 | Ctrl+S、Esc、Ctrl+C 或 Enter |
| 录像 | Ctrl+R |

### 文字识别与翻译

框选后点击「识别文字」或按 Ctrl+O。PP-OCRv6 Small 在本机识别中英文，识别结果可编辑和复制。

在工作台打开「AI 翻译设置」，填写自己的 DeepSeek API Key 并保存。Key 保存在 Windows 凭据管理器。识别结果窗口也可打开该设置。选好目标语言并点击「翻译」后，DeepSeek Flash 只接收待翻译文本。可单独复制译文。

### 扫码、滚动截图与录像

扫码在本机执行。识别结果以标记显示在码的位置，可复制文本或打开检测到的网页链接。

滚动截图默认沿竖向拼接，Alt+H 切换横向，Alt+V 切回竖向。滚动时选区旁实时更新拼接缩略图，Alt+A 切换自动滚动，拖动缩略图两端的裁剪线可缩短输出。Ctrl+C 或 Enter 复制，Ctrl+S 保存，Ctrl+F 固定到屏幕，Esc 或 L 返回普通截图。

在截图工具栏进入录像，选择 MP4、GIF 或 WebP。MP4 可录制麦克风和 Windows 默认播放设备的声音。用 Ctrl+S 开始或结束，空格暂停或继续。录制时点击画笔按钮进入标注模式，可在区域内使用截图标注工具。再次点击或按 Esc 可恢复桌面操作，已有标注继续显示。结束后按 Ctrl+E 保存，文件夹按钮可打开默认录像目录或最近保存的位置。

## 验证

~~~powershell
python -m pytest
~~~

复制、另存或贴图成功后，`AppController.output_succeeded` 提供输出服务使用的不可变快照、任务结果和来源（`copy`、`save` 或 `pin`）。历史服务可按会话 ID 和结果修订号去重。
