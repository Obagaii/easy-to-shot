# Easy to Shot

Windows 桌面截图工具。通过工作台、托盘或全局热键开始截图，框选后可以标注、复制或另存为 PNG。

## 本地运行

使用 Windows 11 x64 和 Python 3.13。在 PowerShell 中执行：

~~~powershell
python -m pip install ".[test]"
python -m e2s
~~~

- 默认截图热键为 Ctrl+Shift+F8。可在工作台查看本次运行的实际热键，也可录入并应用其他组合。
- 拖动鼠标框选，松开后立即显示标注工具条。拖动边框或在“选择”工具下拖动选区空白处可移动选区，拖动四角或四边中点可缩放。拖动期间工具条隐藏，松开后在新位置显示。
- 方向键每次移动选区 1 像素，按住 Shift 每次移动 10 像素。调整选区时，标注固定在原截图像素位置，并随选区裁剪。
- 工具条提供矩形、椭圆、直线、箭头、自由画笔和文字。切到“选择”并点击元素后，可拖动元素或拖动紫色手柄调整大小。直线和箭头可拖动端点，文字可等比缩放。按 Delete 或点击工具栏的“删除”移除元素。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
- 用文字工具单击放置，双击已有文字重新编辑。Enter 换行，Ctrl+Enter 提交，Esc 取消本次文字编辑。其他时候按 Esc 取消截图。
- Ctrl+C 把合成图复制到剪贴板，Ctrl+S 另存为 PNG。复制或保存成功后关闭截图遮罩。
- 关闭工作台后程序仍驻留托盘。从托盘菜单选择“退出”结束进程。

## 验证

~~~powershell
python -m pytest
~~~

复制或保存成功后，`AppController.snapshot_ready` 发出独立的 `OutputSnapshot`。它包含与预览共用渲染规则生成的选区像素，可交给后续历史服务。
